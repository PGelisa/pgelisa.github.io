Geofag 2: Miniconda og JupyterLab

Denne siden viser hvordan du installerer Miniconda, lager et Python-miljø for Geofag 2, og bruker JupyterLab til å åpne, lage og lagre notebooks.

1. Installasjon 2. Lage miljø 3. Jobbe i JupyterLab Vanlige feil

1. Installer Miniconda

Miniconda er en liten pakke som gjør det enkelt å installere Python og fagbiblioteker på en trygg måte. Installer riktig versjon for din maskin.

Mac med Apple Silicon (M1, M2, M3 ...)

  1. Gå til Miniconda installasjon.
  2. Last ned Miniconda3-latest-MacOSX-arm64.pkg.
  3. Dobbeltklikk på filen og fullfør installasjonen.
  4. Åpne Terminal etterpå.

Mac med Intel

  1. Last ned Miniconda3-latest-MacOSX-x86_64.pkg.
  2. Kjør installasjonen og åpne Terminal etterpå.

Windows

  1. Last ned Miniconda for Windows 64-bit.
  2. Kjør installasjonsfilen.
  3. Åpne en ny Kommandoprompt eller PowerShell etterpå.
Ikke installer Anaconda. I Geofag 2 holder det med Miniconda, som er mindre og enklere.

2. Klargjør conda første gang

På Mac må conda kobles til standardskallet ditt. macOS bruker vanligvis zsh.

conda init zsh

Lukk terminalvinduet og åpne et nytt terminalvindu etterpå.

Hvis alt virker, ser du ofte (base) først i terminalen når du åpner et nytt vindu.

3. Legg til riktig kanal og lag miljøet

Noen geofag-pakker, som netCDF4 og cartopy, finnes best via conda-forge. Derfor legger vi til den kanalen og bruker streng prioritet.

conda config --add channels conda-forge
conda config --set channel_priority strict

Lag deretter et nytt miljø som heter geofag2:

conda create -n geofag2 python=3.13 jupyterlab numpy pandas matplotlib scipy geopandas netCDF4 xarray cartopy

Når du får spørsmålet Proceed ([y]/n)?, skriver du y og trykker Enter.

4. Start miljøet og åpne JupyterLab

Hver gang du skal jobbe, gjør du dette i terminalen:

conda activate geofag2
jupyter lab

Da åpnes JupyterLab i nettleseren din. Det kjører lokalt på maskinen din og kan brukes offline når miljøet først er installert.

5. Slik jobber du i JupyterLab

Lage en ny notebook

  1. Se på filpanelet til venstre.
  2. Klikk på + for å åpne Launcher.
  3. Klikk på Python under Notebook.

Åpne en notebook fra lærer

  1. Last ned filen som læreren har delt, vanligvis en .ipynb-fil.
  2. Lagre filen i en mappe du finner igjen, for eksempel Geofag2.
  3. I JupyterLab kan du dobbeltklikke på filen i filpanelet for å åpne den.

Lagre arbeidet ditt

  • JupyterLab lagrer ofte automatisk.
  • Du kan også velge File → Save Notebook.
  • Gi filene tydelige navn, for eksempel havstrommer-oppgave-1.ipynb.

Kjøre kode

  • Skriv kode i en celle.
  • Trykk Shift + Enter for å kjøre cellen.

6. Test at alt virker

Lag en ny notebook og prøv denne koden:

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import xarray as xr

x = np.linspace(0, 10, 100)
y = np.sin(x)

plt.plot(x, y)
plt.title("Testfigur")
plt.show()

Hvis du får en figur, fungerer miljøet ditt.

Vanlige feil

Feil 1: conda: command not found

Åpne en ny terminal. På Mac kan du også kjøre:

conda init zsh

Feil 2: Pakker blir ikke funnet

Pass på at du har aktivert riktig miljø:

conda activate geofag2

Feil 3: Du skrev feil pakkenavn

Det riktige navnet er netCDF4, ikke netCD4 eller netcd4.

Feil 4: JupyterLab starter ikke

Prøv først:

conda activate geofag2
jupyter lab
